## EXPRESSION VARIANTS

### NEUTRAL
Expression: calm, relaxed expression, neutral face, natural resting expression
Use: Default state, baseline for comparison

### HAPPY
Expression: genuine smile, warm expression, eyes crinkling slightly, pleased
Use: Positive moments, victories, connection scenes

### SAD
Expression: downcast eyes, slight frown, melancholic expression, subdued
Use: Loss, disappointment, vulnerability

### ANGRY
Expression: furrowed brow, tense jaw, intense glare, frustrated expression
Use: Conflict, confrontation, determination

### SURPRISED
Expression: wide eyes, raised eyebrows, slightly open mouth, startled
Use: Revelations, shock moments, discoveries

### DETERMINED
Expression: set jaw, focused eyes, resolute expression, intense concentration
Use: Key decision moments, preparing for action

### VULNERABLE
Expression: soft eyes, slightly uncertain, guard lowered, open expression
Use: Intimate moments, confession scenes, connection

## NEGATIVE PROMPT

multiple people, full body, action pose, dramatic background, props, harsh contrast, blurry, deformed features, asymmetrical face, wrong eye color, wrong hair, {{CHARACTER_NEGATIVE_PROMPTS}}

## RECOMMENDED SETTINGS

- Aspect ratio: 1:1 (square portrait)
- Steps: 28
- Guidance: 3.5
- Reference weight: 0.95 (high consistency)
- Reference image: turnaround.png

## REFERENCE IMAGE USAGE

CRITICAL: Use character turnaround as reference image with high weight (0.95)
This ensures facial features remain consistent across expressions.
