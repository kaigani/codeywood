# Use for: Primary character reference after hero shot approval
# Model: Nano Banana Pro / recraft-v3
# Version: 2.0

## DESIGN PHILOSOPHY

This template uses specific panel descriptions rather than abstract "turnaround" concepts.
AI generators respond better to concrete layout instructions than generic reference sheet terms.

## NEGATIVE PROMPT

multiple characters, multiple people, crowd, duplicate figures, photography, realistic photo, blurry, low quality, deformed, extra limbs, missing limbs, bad anatomy, extra fingers, missing fingers, fused fingers, long neck, distorted face, {{CHARACTER_NEGATIVE_PROMPTS}}

## RECOMMENDED SETTINGS

- Aspect ratio: 3:2 landscape (1536x1024)
- Steps: 28
- Guidance: 3.5
- Style reference weight: 0.85 (if using locked style ref)
- Character reference weight: 0.90 (if iterating on existing ref)

## SUBSTITUTION VARIABLES

Core data (from CANON_DB.json → characters.{ID}):
- {{CHARACTER_DESCRIPTION}}: visual.description
- {{OUTFIT_DESCRIPTION}}: visual.signature_outfit
- {{CHARACTER_NEGATIVE_PROMPTS}}: visual.negative_prompts

Expression variables:
- {{EYE_DETAILS}}: "iris detail and eye shape" OR specific notes like "amber-flecked hazel iris"
- {{MOUTH_EXPRESSION}}: "natural closed-lip expression" OR "slight knowing smirk"
- {{NEUTRAL_EXPRESSION}}: "neutral expression" OR character-appropriate default
- {{EXPRESSION_1}}: First expression (e.g., "angry expression")
- {{EXPRESSION_2}}: Second expression (e.g., "slight smile")
- {{EXPRESSION_3}}: Third expression (e.g., "weary/tired look")
- {{HAND_DESCRIPTION}}: "natural hand gesture with fingers relaxed" OR character-specific

Style data (from project style refs):
- {{STYLE_KEYWORDS}}: From STYLEGUIDE_VISUAL.md → global aesthetic keywords
- {{HEX_PALETTE}}: Extracted from locked style reference (8-12 hex codes)

## QUALITY CHECKLIST

After generation, verify:
- [ ] All specified panels present and readable
- [ ] Eye close-up shows clear iris detail
- [ ] Hero portrait is prominently placed
- [ ] Expression variations are distinct but consistent
- [ ] Hand reference shows correct finger count and natural position
- [ ] Full body shows complete outfit, both front and back
- [ ] Proportions consistent across all panels
- [ ] Grid layout is clean with visible dividers
- [ ] Color palette matches provided hex codes
- [ ] Style matches locked style reference

## IF GENERATION FAILS

Common issues and fixes:
- **Panels merging**: Add "clearly separated panels with black dividing lines"
- **Missing panels**: Simplify to fewer panels, generate additional sheets separately
- **Hand issues**: Use higher guidance (4.0) and add "anatomically correct hands"
- **Inconsistent face**: Increase style/character reference weight
- **Wrong colors**: Verify hex palette is formatted correctly with brackets and quotes
- **Style drift**: Increase style reference weight to 0.90

## COMPARISON: OLD vs NEW APPROACH

OLD (v1.0 turnaround.txt):
"character design reference sheet, turnaround view showing front, side, back"
→ Inconsistent results, model interprets "turnaround" differently each time

NEW (v2.0 identity_sheet.txt):
Explicit panel-by-panel description of exact layout
→ Consistent, predictable results with all reference elements needed
