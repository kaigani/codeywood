After generation, verify:
- [ ] All four views present and distinct
- [ ] Proportions consistent across views

## IF GENERATION FAILS

Common issues and fixes:
- Views not distinct: Add "clearly separated panels" to prompt
- Inconsistent features: Increase specificity of description
- Wrong style: Strengthen style keywords
- Background issues: Emphasize "clean white background, studio setting"
